## 一、穿越机单轴 rate 回路建模

### 1.1 物理结构

```
setpoint ω* ──►(+)──►[PID 控制器]──► m ──►[电机+机体]──┬──► ω (gyro)
               ▲(-)                                     │
               └────────────────────────────────────────┘
```

### 1.2 各环节传递函数

| 环节 | 传递函数 | 说明 |
|---|---|---|
| 电机 | `K_m / (τ_m·s + 1)` | 一阶滞后，τ_m ≈ 5~15ms |
| 机体（力矩→角速度）| `1 / (J·s)` | 纯积分（转动惯量 J）|
| 合并被控对象 G(s) | `K_plant / (s·(τ_m·s + 1))` | K_plant = K_m / J |
| PID 控制器 C(s) | `Kp + Ki/s + Kd·s` | 标准 PID（FF 单独处理）|

### 1.3 开环与闭环

开环传递函数：
```
L(s) = C(s)·G(s) = (Kp + Kd·s + Ki/s) · K_plant / (s·(τ_m·s + 1))
```

闭环特征方程 `1 + L(s) = 0`。**先分析 PD 主导（Ki=0）**，因为穿越机瞬态由 PD 决定，I 只管稳态。

## 二、PD 闭环特征方程推导（Ki=0）

### 2.1 特征方程

```
1 + (Kp + Kd·s) · K_plant / (s·(τ_m·s + 1)) = 0

→ s·(τ_m·s + 1) + K_plant·(Kp + Kd·s) = 0

→ τ_m·s² + s + K_plant·Kp + K_plant·Kd·s = 0

→ τ_m·s² + (1 + K_plant·Kd)·s + K_plant·Kp = 0
```

### 2.2 标准化对比

除以 τ_m，对比标准二阶 `s² + 2ζωn·s + ωn² = 0`：

```
s² + [(1 + K_plant·Kd)/τ_m]·s + [K_plant·Kp/τ_m] = 0
```

### 2.3 ★ 解析映射公式（核心结论）

```
┌─────────────────────────────────────────────────────────┐
│  ωn = √(K_plant·Kp / τ_m)                               │
│                                                          │
│  ζ  = (1 + K_plant·Kd) / (2·τ_m·ωn)                     │
│     = (1 + K_plant·Kd) / (2·√(τ_m·K_plant·Kp))          │
└─────────────────────────────────────────────────────────┘
```

### 2.4 比例关系（修复代码用的就是这个）

设基准态 `(Kp₀, Kd₀)` 对应 `(ωn₀, ζ₀)`，变化到 `(Kp, Kd)`：

```
ωn / ωn₀ = √(Kp / Kp₀)                          ← P 开方关系

ζ / ζ₀  = [(1 + K_plant·Kd) / (1 + K_plant·Kd₀)] · √(Kp / Kp₀)
```

当 `K_plant·Kd ≫ 1`（穿越机典型情况，D 主导阻尼）时简化：

```
ζ / ζ₀ ≈ (Kd / Kd₀) · √(Kp₀ / Kp)              ← D 正比，P 反开方
```

## 三、现有代码的错误对照

`PIDRecommendationEngine.m:117-126`：

```objc
gain *= (recommended.p / original.p);            // ❌ 错
zeta *= sqrt(recommended.d / original.d);         // ❌ 错
wn *= pow(recommended.ff / original.ff, 0.3);     // ❌ 错
```

| 项 | 现有代码 | 推导结论 | 错误性质 |
|---|---|---|---|
| **P** | `gain *= p_ratio`（P 改增益 K）| `ωn *= √p_ratio`（P 改自然频率）| 🔴 方向错（K vs ωn）|
| **D** | `zeta *= √d_ratio`（D 开方改 ζ）| `zeta *= d_ratio·√(p₀/p)`（D 正比改 ζ）| 🔴 函数形式错（开方 vs 正比）|
| **FF** | `wn *= ff_ratio^0.3`（FF 改 ωn）| FF **不进** ωn，独立前向通道 | 🔴 物理位置错 |

**关键洞察**：
- 二阶闭环的 DC 增益 `T(0) = ωn²/ωn² = 1`，**P 不改变稳态增益**——现有代码让调 P 表现为"幅度缩放"，与物理完全相反。
- P 和 D 是**耦合**的：调 P 会同时改 ωn 和 ζ（因为 ζ ∝ 1/√Kp）。现有代码把它们独立处理，丢掉了耦合。

## 四、I 项建模（缺陷②修复）

### 4.1 为什么二阶模型"表达不了 I"

加入 I 后，特征方程变成三阶：
```
τ_m·s³ + (1 + K_plant·Kd)·s² + (K_plant·Kp + Ki)·s + K_plant·Ki = 0
```
不再是二阶。但 I 的作用有清晰物理意义：**消除稳态误差**。

### 4.2 工程化建模：附加稳态收敛项

I 不显著改变瞬态形状（ωn/ζ 由 PD 决定），但影响**建立阶段的尾巴**。

建模方法：在二阶预测曲线上叠加一个慢收敛的稳态修正项：

```
predicted(t) = T_2ndOrder(t)  +  Δsteady(t)

Δsteady(t) = (1 - T_2ndOrder(∞)) · (1 - exp(-t/τ_I))    where τ_I = Kp / Ki
```

- `τ_I = Kp/Ki` 是积分时间常数（标准控制理论定义）
- Ki 越大 → τ_I 越小 → 稳态误差消除越快
- 这给了 I 一个**独立的、可预测的**曲线影响，不再"丢失"

### 4.3 数值示例

```
Kp=45, Ki=80 → τ_I = 45/80 = 0.5625 s
Kp=45, Ki=160（I 翻倍）→ τ_I = 0.28 s（稳态收敛快一倍）
```

I 翻倍不改变 ωn/ζ（瞬态形状不变），但稳态尾巴收敛快一倍——符合飞行手感。

## 五、FF 项建模（缺陷①的 FF 部分）

### 5.1 FF 的物理位置

FF 不在反馈环内，是 setpoint 的**直接前向注入**：

```
output = [Kp·e + Kd·de/dt + Ki·∫e dt]  +  Kf·(dω*/dt)    ← FF 在前向通道
        └────── 反馈项 ──────┘            └── 前馈项 ──┘
```

### 5.2 预测曲线建模

闭环输出 = 反馈响应 + 前馈注入：
```
predicted(s) = T_cl(s)·R(s) + Kf·s·R(s)   （R 是 setpoint，FF 取微分形式）
```

对阶跃输入 `R(s) = 1/s`：
```
predicted(t) = T_cl_step(t) + Kf·δ(t)     ← FF 在 t=0 注入一个冲击
```

工程上更常见的是 FF 取比例形式（BF 的 FF 实际是 setpoint 微分经过滤波），简化为：
```
predicted(t) ≈ T_cl_step(t) · (1 + Kf·shape(t))
```
其中 `shape(t)` 是 FF 影响的时域窗（集中在上升阶段）。

### 5.3 结论

FF **不进 ωn/ζ/K 任一参数**。它影响的是上升阶段的"跟手度"。建模时作为独立的瞬态叠加项处理。

## 六、修复后的完整映射

### 6.1 新映射公式总表

| PID 变化 | 影响的二阶/附加参数 | 映射关系 |
|---|---|---|
| **Kp 变化 (p_ratio)** | ωn, ζ（耦合）| `ωn *= √p_ratio`；`ζ /= √p_ratio` |
| **Kd 变化 (d_ratio)** | ζ | `ζ *= d_ratio` |
| **Ki 变化 (i_ratio)** | 积分时间常数 τ_I | `τ_I /= i_ratio`（影响稳态尾巴）|
| **Kf 变化 (ff_ratio)** | 前馈瞬态项 | 独立叠加，不改 ωn/ζ/K |

### 6.2 修复后的预测曲线生成

```objc
// 1. 从基准曲线拟合基准二阶参数
fitSecondOrderFromResponse(measured) → (K₀, ωn₀, ζ₀)

// 2. 按 PID 变化修正（PD 主导）
double pRatio = newP / oldP;
double dRatio = newD / oldD;
double ωn = ωn₀ * sqrt(pRatio);              // P 开方关系
double ζ  = (ζ₀ * dRatio) / sqrt(pRatio);     // D 正比 / P 开方
ζ = clamp(ζ, 0.1, 2.0);

// 3. K 不变（二阶闭环 DC 增益恒为 1）
double K = K₀;

// 4. 生成 PD 主导的二阶曲线
predicted = predictedCurveWithGain(K, ωn, ζ);

// 5. 叠加 I 的稳态收敛修正
if (newI != oldI) {
    double τI = newP / newI;                  // 积分时间常数
    predicted = applySteadyStateCorrection(predicted, τI);
}

// 6. 叠加 FF 的前馈瞬态
if (newFF != oldFF) {
    predicted = applyFeedforwardTransient(predicted, ff_ratio);
}

return predicted;
```

## 七、数值验证（合理性检查）

### 7.1 基准态

```
Kp₀=45, Kd₀=30 → 典型穿越机
假设 ωn₀ = 2π·50 = 314 rad/s（50Hz 带宽）
反推 K_plant/τ_m = ωn₀²/Kp₀ = 314²/45 ≈ 2191
```

### 7.2 P 翻倍（Kp: 45→90）

```
ωn = ωn₀ · √2 = 314 · 1.414 = 444 rad/s ≈ 70Hz  ← 带宽提升，正确
ζ  = ζ₀ / √2 = 0.7 / 1.414 = 0.495              ← 阻尼下降（更震荡），符合"高P易震"
```
**与 Oscar Liang 经验"P 调高会震荡"完全一致** ✓

### 7.3 D 翻倍（Kd: 30→60）

```
ωn 不变                                          ← D 不影响带宽，正确
ζ  = ζ₀ · 2 = 1.4                                ← 阻尼翻倍（更稳），符合"D 抑制震荡"
```
**与"加 D 压震荡"完全一致** ✓

### 7.4 对照现有代码的错误结果

P 翻倍时现有代码：`gain *= 2` → 曲线幅度翻倍（错，应是变快）
D 翻倍时现有代码：`zeta *= √2 = 1.414` → 阻尼×1.414（接近正确值 2，但是巧合，函数形式错）
