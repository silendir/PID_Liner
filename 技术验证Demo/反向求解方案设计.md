## 〇、2.5b 结果判定（先回答"能不能进反解"）

### 0.1 一个必须澄清的精度区分 🔑

| 精度类型 | 含义 | 2.5b 是否测了 | 反解是否依赖 |
|---|---|---|---|
| **fit 精度** | 真实曲线 → fit → (K,ωn,ζ) → 回放 vs 真实 | ✅ 测了，RMSE=0.067 | ❌ **不直接依赖** |
| **forward 精度** | 给定 PID → forward 模型 → 曲线 vs 真实 | ⚠️ 2.5a 间接测（合成闭环≈0）| ✅ **反解的生命线** |

**2.5b 的 0.067 测的是"二阶模型能否表达真实曲线"**，不是"forward(PID) 能否预测真实曲线"。这俩方向相反：
- fit：曲线 → 参数（压缩，信息丢失在此）
- forward：参数 → 曲线（展开，反解用的是这个）

### 0.2 判定结论

**RMSE=0.067 → 二阶骨架够用，反解可进，但前向必须轻量扩展（见选型 3）。**

理由：
1. 形状对（方波单段阶跃）→ 模型**阶次**没错，误差来自拟合方法粗糙（`1.8/trise` + 单点超调反算 ζ）+ 提纯残留
2. 0.067 是"压缩再展开"的损失；反解走"直接拟合"（见 §一），绕过这道压缩
3. 2.5a 证明 forward 模型数值正确，可作为反解的内部黑盒

## 一、核心架构决策：反解走"直接数值优化"，不走"fit→反查表"

> 这是整套方案的根。选错路径，后面三个选型全白做。

### 1.1 两条路径对比

```
❌ 错误路径（fit→反查表）：
  targetCurve ──fit──► (K,ωn,ζ) ──反查PID──► PID
  致命问题：二阶只有 3 维，4 PID 欠定；且 fit 丢信息（§0.1）

✅ 正确路径（直接数值优化）：
  targetCurve ◀──minimize‖target - forward(PID)‖²── forward(PID)
  优势：曲线 N 点(4000) >> 4 未知 → 天然过定 → 4 PID 全可解
```

### 1.2 为什么"直接拟合"绕过了二阶的 3 维瓶颈

二阶模型的 3 维限制只在**fit 方向**存在（曲线→3 参数）。反解走 forward 方向：
- `forward(PID)` 可以是**扩展模型**（二阶 + I 稳态项 + FF 瞬态项，见选型 3）
- 曲线 4000 个采样点 = 4000 个约束，解 4 个 PID 绰绰有余
- 不需要"曲线→二阶→PID"的中转，二阶只是 forward 内部的参数化手段

**这条决策把战略调研 §6.2 的"4 vs 3 欠定"问题转化为"4000 vs 4 过定"问题。** 病态性大幅缓解（但没消失，见选型 1 的正则化）。

## 二、选型 1：第 4 维约束 → 全曲线最小二乘 + Tikhonov 正则化

### 2.1 战略调研给的三条出路

| 路线 | 机制 | 评价 |
|---|---|---|
| 路一：曲线 + 风格先验 | 曲线给 (K,ωn,ζ)，风格旋钮给第 4 维 | ⚠️ 仍受二阶 3 维限，且 I 几乎不影响瞬态曲线，约束弱 |
| 路二：全曲线最小二乘 | 匹配整条曲线每点，过定解 4 PID | ✅ 数学最干净，配合 §一 的直接拟合天然成立 |
| 路三：正则化 + 风格偏置 | 代价 = ‖残差‖ + λ·‖偏离当前PID‖ + μ·风格奖励 | ✅ 融合路一路二，且解决病态 |

### 2.2 选定：路二为主 + 路三的正则化项

```
代价函数 J(PID) = ‖targetCurve - forward(PID)‖²    ← 路二：曲线拟合主项
                + λ · ‖PID - PID_current‖²          ← 路三：Tikhonov 正则化
                + μ · styleReward(PID)              ← 路三：风格偏置（可选，=产品层的风格旋钮）
```

**为什么这么选**：
1. **过定**（4000 点 vs 4 未知）→ 数学上 4 PID 都能解，不需手选第 4 维
2. **Tikhonov 正则化**解决残余病态：保证解接近当前 PID（微调而非重算），这正是"风格化调音"的数学表达——用户在现有手感上雕塑，不是推倒重来
3. **风格旋钮**作为正则化偏置 `μ·styleReward`，而非硬约束 —— 产品层"风格 EQ 旋钮"和市场层"小白要简单"一次性解决（呼应战略调研 §5.2）
4. **λ 是风格化的关键旋钮**：λ 大 → 解贴近当前值（保守微调）；λ 小 → 解大幅跟随目标曲线（激进重塑）。用户可调。

### 2.3 否决纯路一的理由

纯路一依赖"二阶 3 维 + 风格补 1 维"，但前向推导 §四证明 **I 项在二阶瞬态里几乎不可见**（I 只影响稳态尾巴 τ_I）。所以即便风格旋钮补了 FF，I 项仍无解。必须走全曲线拟合才能把 I 从稳态尾巴段解出来。

## 三、选型 2：数值优化器 → Levenberg-Marquardt（LM）

### 3.1 候选对比

| 优化器 | 迭代格式 | 优点 | 致命点 |
|---|---|---|---|
| 高斯-牛顿（GN）| `Δ=(JᵀJ)⁻¹Jᵀr` | 二次收敛，快 | `JᵀJ` 病态时崩——反解正好病态 |
| **LM** | `Δ=(JᵀJ+λD)⁻¹Jᵀr` | GN 与最速下降的插值，λ 自适应 | 实现稍复杂 |
| 梯度下降 | `Δ=-η∇J` | 简单 | 收敛慢，η 难调 |

### 3.2 选定：LM

理由：
1. **反问题病态**（§6.2）→ `JᵀJ` 必奇异 → GN 必崩；LM 的阻尼项 `(JᵀJ+λD)` 正好治这个
2. LM 的阻尼 λ **与选型 1 的正则化 λ 同源**，可统一调参
3. 4 参数小问题，LM 收敛极快（< 20 次迭代），iOS 上计算量不是瓶颈
4. Accelerate.framework 的 `vDSP`/`vForce` 可辅助矩阵运算（解 4×4 线性方程组）

### 3.3 雅可比：用数值差分，不强行解析

`forward(PID)` 对 PID 的偏导，用前向差分：

```
∂forward/∂p_i ≈ [forward(PID + h·e_i) - forward(PID)] / h
```

- 4 参数 → 每次迭代 4 次额外 forward 调用
- 解析雅可比需处理 `sqrt`/`clamp`/分段函数，复杂易错；数值差分简单可靠
- 代价：每迭代 5 次 forward（1 次 residual + 4 次 Jacobian），可接受

## 四、选型 3：前向模型 → 轻量扩展（加 I/FF 项），不换二阶骨架

### 4.1 为什么纯二阶不够

纯二阶 `(K,ωn,ζ)` 只有 3 个内部参数：
- I 项丢失（前向推导 §四，审计缺陷②）
- FF 项丢失（前向推导 §五）
- → forward(P,I,D,FF) 实际只输出 3 个自由度的曲线，4→3 信息丢失，反解 I/FF 无依据

### 4.2 选定：扩展二阶（二阶骨架 + I 稳态项 + FF 瞬态项）

直接采用前向推导 §四/§五 已推导的扩展形式：

```
forward(t; P,I,D,FF) = T_2ndOrder(t; K,ωn,ζ)        ← 二阶骨架，由 PD 决定
                      + Δsteady(t; τ_I)              ← I 稳态收敛项
                      + Kf · shape(t)                ← FF 前馈瞬态项

其中：
  ωn = √(K_plant·P / τ_m)          ← 绝对映射（非 ratio！见 §六）
  ζ  = (1 + K_plant·D) / (2·√(τ_m·K_plant·P))
  τ_I = P / I
  Kf  = FF（前向推导 §5.2 简化）
```

**这是"扩展"，不是"换模型"**：二阶骨架不变（2.5b 验证够用），只是补回被吞掉的 I/FF。工程量小。

### 4.3 否决"升级到高阶/状态空间模型"的理由

审计 §三缺陷④列了 D-term 动态滤波/TPA/Setpoint shaping 等二阶表达不了的特性。但：
1. 这些是**高频/油门相关**特性，在用户雕塑的**时域低频目标曲线**上影响小
2. 升级到状态空间模型 = 研究课题（两周量级变两月），违背战略调研 §6.6 "不需要新算法"的判定
3. **留校准门兜底**（§五）：若某 BBL 拟合 RMSE 过高，提示用户"前向未对齐"，不强行反解

### 4.4 forward 精度待验证（开放实验）

2.5b 测的是 fit 精度。**forward 精度**（扩展模型 vs 真实曲线）还没直接测。建议反解编码前补一个小实验：

```
阶段 2.5c（可选，token 小）：
  真实 BBL → 已知 PID(P,I,D,FF) → forward(P,I,D,FF) → vs 真实曲线 → RMSE
  判定：forward RMSE < 0.1 → 扩展模型够，进反解编码
        forward RMSE ≥ 0.1 → 扩展不够，回头补 D-term 尾巴
```

这个实验比 2.5b 更直接回答反解可行性。

## 五、校准门与失败处理（防 garbage in）

### 5.1 双层质量门

```
门 1（fit 门，已有）：targetCurve → fit → 回放 RMSE
  < 0.1 → 目标曲线本身是干净二阶形状，可反解
  ≥ 0.1 → 用户雕塑出二阶表达不了的形状 → 提示"该形状无法用 PID 实现，请回调"

门 2（forward 门，新加）：反解出 PID 后 → forward(PID) → vs targetCurve RMSE
  < 0.1 → 反解成功，PID 可用
  ≥ 0.1 → LM 未收敛或前向不够 → 回退 PID_current，提示"请再飞一轮校准"
```

### 5.2 失败处理

| 失败模式 | 检测 | 处理 |
|---|---|---|
| LM 不收敛 | 迭代次数超上限 | 回退当前 PID，提示风格旋钮调小（增大 λ）|
| 解出 PID 越界 | P/I/D/FF 超物理范围 | clamp + 标记"边界解，可信度低" |
| forward 门未过 | 门 2 RMSE ≥ 0.1 | 不输出 PID，提示"前向模型未对齐此曲线" |
| 机械常数未标定 | K_plant/τ_m 缺失（见 §六）| 拒绝反解，引导先做机标定 |

## 六、🔴 新发现的工程难点：机械常数标定（K_plant / τ_m）

### 6.1 问题

前向推导 §8.3 说"比例关系消除 K_plant/τ_m"——但那是 **fit 方向**（用 ratio 修正现有曲线）。

反解走 forward 方向，需要**绝对值**：

```
forward 需要：ωn = √(K_plant·P / τ_m)   ← 必须知道 K_plant 和 τ_m 的绝对值
```

不知道这两个机械常数，forward 算不出绝对曲线，LM 的 residual 无意义。

### 6.2 标定方案（一次性，存飞机档案）

用一条**已知 PID 的校准 BBL** 反推：

```
已知：PID_known(P,I,D,FF) + 实测曲线 measuredCurve
步骤：
  1. fit(measuredCurve) → (K, ωn, ζ)
  2. 由 ωn = √(K_plant·P/τ_m) 和 ζ = (1+K_plant·D)/(2√(τ_m·K_plant·P))
     两个方程，两个未知 (K_plant, τ_m) → 解出
  3. 存入飞机档案（与 craftName 关联）
```

- 一架飞机标定一次（机械常数不随 PID 变）
- 存储复用已有 `IterationChain` 的 craftName 路由
- **这是反解的前置条件**：未标定的飞机，反解拒绝执行

### 6.3 标定的不确定性

K_plant/τ_m 从单个 BBL 标定，受 fit 精度（0.067）影响 → 标定值有误差 → 传递到反解。建议：
- 多轮 BBL 标定取中位数
- 标定值带置信度，反解结果继承标注

## 七、反解算法骨架（伪代码，不实现）

```objc
// 前置：飞机已标定 (K_plant, τ_m)，存飞机档案
// 输入：targetCurve（用户雕塑）+ PID_current（当前值）+ styleKnob（风格旋钮，0~1）
// 输出：recommendedPID 或 nil（失败）

- (PID *)reverseSolveWithTarget:(NSArray *)targetCurve
                      currentPID:(PID *)current
                 mechConstants:(MechConst)mc
                      styleKnob:(double)style {
    // 门 1：targetCurve 自身可拟合性
    double fitRMSE = [self fitReplayRMSE:targetCurve];
    if (fitRMSE > 0.1) return nil;  // 形状二阶表达不了

    // LM 迭代
    PID *guess = current;
    double lambda = 0.01 * (1.0 + style);  // 风格旋钮调 λ

    for (int iter = 0; iter < 20; iter++) {
        NSArray *residual = subtract(targetCurve, forward(guess, mc));
        double J = dot(residual, residual) + lambda * normSq(guess - current);

        // 数值雅可比（4 次 forward）
        Matrix jac = numericJacobian(guess, mc);  // 4000×4
        // LM 步长：(JᵀJ + λD) Δ = -Jᵀ·residual
        Vector delta = solveLM(jac, residual, lambda);

        PID *newGuess = clamp(guess + delta);
        NSArray *newResidual = subtract(targetCurve, forward(newGuess, mc));
        double newJ = dot(newResidual,newResidual) + lambda*normSq(newGuess-current);

        if (newJ < J) { guess = newGuess; lambda *= 0.5; }   // 接受，降阻尼
        else          { lambda *= 2.0; }                      // 拒绝，升阻尼

        if (|delta| < 1e-3) break;  // 收敛
    }

    // 门 2：反解结果 forward 拟合度
    double fwdRMSE = rmse(targetCurve, forward(guess, mc));
    if (fwdRMSE > 0.1) return nil;  // 前向未对齐

    return guess;
}
```

**关键**：`forward()` 是唯一的"真实模型"，fit/LM/门 全部围绕它。`BFPIDToSecondOrderMapper`（阶段 2.6 产物）提供 P/D → (ωn,ζ) 的正确映射，需**扩展**为含 I/FF 的完整 forward。
