# 黑盒频带分析识别 TPA/AG 调优需求 —— 方法论 v1

> 2026-10-19 | 数据源：`吴飞行迭代/` 六轮真实迭代 BBL（BETAFPVG473_V3 / Betaflight 2025.12.2 / 1960KV / 994Hz log 采样率 / 油门常驻 1250PWM）
> 验证状态：**本机六轮实测通过；阈值 v1 仅单机型单案例，待多机型/故障样本校准**
> 分析脚本：`/tmp/bb_tpa.mjs`（临时，产品化为 App 噪声图扩展前需固化进仓库）

## 一、背景

六轮 PID 迭代后飞手反馈"缓慢动作与激烈动作无法两全"，怀疑需要引入 TPA/AntiGravity。
本研究用油门分桶 + 频带能量分析，在实测数据上验证"算法能否识别 TPA/AG 的调整需求"。

## 二、方法三组件（全部在六轮实测上走通）

### 组件① 频带定性（TPA 判据 · 核心）

把 gyroADC 按频段分解能量占比，**只看高峰值油门段**：

| 频段 | 含义 | 判据 |
|---|---|---|
| <30Hz | 飞行动作本身（机动频率） | 忽略 |
| **30~150Hz** | **PID/D 项工作区（TPA 管辖）** | 高油门段占比显著抬升（v1 病灶线 >15%）→ **TPA 不足**，升 rate/降 bp |
| 150~300Hz | 高频振荡/机械共振 | 能量集中 → 机械问题，**调 TPA 无用**，查桨/机架 |
| 300Hz+ | 电机噪声 | 被滤波正常压低 |

**本次六轮实测：高油门段 30~150Hz 占比仅 1.0~1.4%，150Hz+ 近零**
→ 判定：**无高频振荡病灶，TPA 保持现状（D 模式 / rate 65 / bp 1350）**。此时升 rate 属于误调。

### 组件② jitter-油门曲线（粗筛 · 不可单独定论）

帧间差分随油门分桶画曲线。**教训：jitter 会被真实机动脉冲污染**——
2轮 jitter 比 4.16 曾被误判"TPA 不足"，频谱复核后 30~150Hz 仅 1%，是机动内容差异非振荡。
正确用法：jitter 异常升高时**必须回到组件①频谱复核**；改进方向：对 gyro 先做 150Hz 高通再取差分，即得纯振荡 jitter。

### 组件③ 油门突变场景计数（AG 前置条件）

统计 |Δ油门(100ms)| >120 PWM 的帧占比：
- **>0**：AG 有介入场景，可诊断（判据：油门突变窗口的响应尾巴下垂量显著 → AG 不足，升 gain；突变后过冲 → AG 过度，降 gain）
- **=0**：**数据盲区，AG 不可诊断**——本次六轮全部为 0（飞手油门平稳），需专门科目（悬停中猛推油 1250→1800 ×3~5 次 + 快速收油 ×3~5 次）

## 三、实测结果汇总（六轮）

| 轮 | 高油门帧 | 突变帧 | 高油门 30~150Hz | 结论 |
|---|---|---|---|---|
| 首轮 | 15% | 0% | — | 短片段 |
| 2轮 | 28% | 0% | 1.0% | 无病灶 |
| 3轮 | 29% | 0% | 1.4% | 无病灶（对照轮） |
| 4/5轮 | 21~27% | 0% | — | 高油门机动帧不足 |
| 6轮 | 27% | 0% | 1.3% | 无病灶 |

另：响应增益比（高/低油门）全部 ≥0.91 → 无"高油门发软" → 无 TPA 过度信号。

## 四、与 airmode 事件的合并结论

六轮中飞手曾遇"缓慢 vs 激烈无法两全"，最终确认**真凶 = airmode 未开启**（低油门混合器钳制惩罚缓慢动作）。
airmode 开启后满意 → 剩余矛盾不在 TPA（本次频谱证实无病灶）。
**AG/TPA 的真正提升空间需在 airmode 就位的新基线上 + AG 专门科目数据** 再评估。

## 六、待校准项

- 病灶线 15%、jitter 比 1.5：**单案例初值**，需多机型/真实故障样本回归
- 频段边界 30/150/300Hz：基于 D 项工作频段常识，可按 looptime/滤波配置微调
- 采样率依赖：本方法假设 1kHz log，低采样率文件需调整 FFT 段长
